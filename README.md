# LifePilot — Alexa+ Action Agent

LifePilot is a web-based prototype inspired by Alexa+ action-oriented assistance. It turns a user's goal into a seven-day plan, lets the user review and approve tasks, and tracks progress.

## Features

- Create personalized seven-day plans for goals.
- Review tasks before approving them.
- Approve tasks and mark them complete or reopen them.
- Save plans and tasks using the project's database integration.
- Use browser-supported voice input and spoken guidance.
- View activity history.

## How It Works

1. Enter a goal, such as preparing for an interview or building a project.
2. Generate a suggested plan.
3. Review and approve the tasks.
4. Track progress as you complete the tasks.

https://lifepilot-alexa.hatchable.site

## Technology

- HTML, CSS, and JavaScript
- Backend API endpoints for planning and task actions
- PostgreSQL database integration through the Hatchable runtime
- Browser Speech Recognition and Speech Synthesis APIs

## Important Note

This is an independent prototype inspired by Alexa+ concepts. It is not an official Amazon Alexa+ integration and does not connect to Amazon Bedrock or a live large language model. Planning currently uses deterministic rules.
