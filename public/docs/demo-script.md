# LifePilot demo script

Target length: 2 minutes 45 seconds. Keep the recording public, in English, and under 3 minutes.

## 0:00–0:20 — Problem and idea
"LifePilot is an Alexa+-style action-agent simulation. It helps users turn a goal into a plan they can inspect and approve, instead of hiding actions behind a chat response."

## 0:20–0:50 — Create a plan
Enter: "Help me prepare for a software engineering interview in 7 days. I have 2 hours each evening." Click Build my action plan. Show the seven daily tasks and categories.

## 0:50–1:20 — Human approval
Point to the pending state. Try clicking a task before approval and show the app refuses completion. Click Approve plan.

## 1:20–1:50 — Complete and verify
Mark one task complete. Show the completed count and progress indicator, then refresh the page to demonstrate the backend persisted the state.

## 1:50–2:20 — Explain trust and boundaries
Show the activity log and explain that the app distinguishes proposed, approved, and completed actions. Be explicit that this is a web simulation, uses deterministic demo planning, and does not connect to a real Alexa+ account, calendar, or external messaging service.

## 2:20–2:45 — Next step
"Next, we want to add voice interaction and a model-backed planner, then validate an official Alexa+/MCP integration against the track's current requirements."
